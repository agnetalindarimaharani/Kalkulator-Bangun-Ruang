🔷 Kalkulator Bangun Ruang (Java PBO)

📌 Deskripsi

Kalkulator Bangun Ruang adalah program berbasis Java yang digunakan untuk menghitung volume dan luas permukaan beberapa bangun ruang. Program ini dibuat dengan menerapkan konsep Pemrograman Berorientasi Objek (PBO) untuk memahami penggunaan class, object, encapsulation, inheritance, abstraction, dan polymorphism.

🎯 Tujuan

- Memahami konsep dasar Pemrograman Berorientasi Objek (PBO).
- Menerapkan penggunaan class dan object dalam Java.
- Memahami konsep inheritance dan polymorphism.
- Membuat program perhitungan bangun ruang secara sederhana.

📐 Fitur Program

Program ini memiliki beberapa pilihan bangun ruang:

1. Kubus
   
   - Menghitung volume.
   - Menghitung luas permukaan.

2. Balok
   
   - Menghitung volume.
   - Menghitung luas permukaan.

3. Tabung
   
   - Menghitung volume.
   - Menghitung luas permukaan.

4. Bola
   
   - Menghitung volume.
   - Menghitung luas permukaan.

5. Keluar
   
   - Mengakhiri program.

🧩 Konsep PBO yang Diterapkan

Konsep PBO| Penerapan
Class| BangunRuang, Kubus, Balok, Tabung, Bola
Object| Membuat objek dari setiap bangun ruang
Encapsulation| Menggunakan atribut private
Inheritance| Class turunan menggunakan extends
Polymorphism| Method perhitungan yang di-override
Abstraction| Menggunakan abstract class BangunRuang

▶️ Cara Menjalankan Program

1. Download atau clone repository ini.
2. Buka Apache NetBeans.
3. Pilih menu File → Open Project.
4. Pilih folder Kalkulator-Bangun-Ruang.
5. Buka file "Main.java".
6. Klik tombol Run atau tekan "F6".
7. Pilih bangun ruang yang ingin dihitung.
8. Masukkan ukuran sesuai permintaan program.
9. Hasil volume dan luas permukaan akan ditampilkan.
